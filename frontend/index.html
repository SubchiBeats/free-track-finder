Audio converter

Convert a track you've downloaded to the format your DJ software prefers (WAV/AIFF for Serato & rekordbox). Files are processed locally and never leave your machine.

ffmpeg isn't installed. The converter needs it. On Windows run winget install ffmpeg in PowerShell, then restart the server.

Note: converting an MP3 to WAV changes the container for compatibility — it can't restore quality lost to MP3 compression.
